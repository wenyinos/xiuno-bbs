# xn_sso · wenyinos 统一认证接入插件

将论坛接入 [玟茵开源社区统一认证中心](https://wenyinos.com/auth)：登录 / 注册 / 退出 / 改密 全部由认证中心统一处理，已登录主站后访问论坛自动通行。

## 功能一览

| 功能 | 说明 |
|---|---|
| 登录定向 | 论坛登录页自动跳转认证中心登录页 |
| 登录态继承 | 中心登录后访问论坛自动登录（wy_auth 票据静默兑换） |
| 未开通处理 | 持票据但中心未开通论坛 → 任意前台页面定向回中心（面板显示原因）；中心退出后恢复游客浏览 |
| 全域退出 | 论坛退出 = 销毁中心票据 + 清本地会话 + 回中心登录页 |
| 单点登出 | 已登录用户写操作每 30 分钟校验一次中心票据；中心登出后本地会话随之失效（中心不可达时静默降级） |
| 安全基线 | 站点名/标题输出转义；`bbs_token`/`bbs_sid` cookie 带 HttpOnly + SameSite（按协议动态 Secure） |
| 注册关闭 | 前台自助注册关闭，账号统一由中心管理 |
| 改密同步 | 论坛内改密成功后自动同步到中心 |
| 降级容灾 | 中心不可达时，游客浏览不受影响（不产生报错） |

## 统一认证总开关

**后台 → 插件 → 统一认证（wenyinos SSO）→ 设置**，首项即「统一认证开关」：

- **启用**（默认）：以上所有功能生效
- **停用**：立即恢复论坛**原生**登录 / 注册 / 退出，票据兑换停止——用于中心故障或需要临时脱离统一认证时

开关值保存在插件 kv（`xn_sso.enabled`），停用/启用即时生效，无需改任何代码或文件。

## 设置项说明

| 设置项 | 说明 | 示例（生产） |
|---|---|---|
| 统一认证开关 | 见上 | 启用 |
| 中心 API 地址 | 认证中心 API 入口 | `https://wenyinos.com/auth/api.php` |
| 应用标识 | 中心「应用密钥」页签发 | `forum` |
| 应用密钥 | 与中心配对，保密 | `<64位hex>` |
| 超时（秒） | API 请求超时，超时视为中心不可达 | `3` |
| 中心登录页地址 | 登录跳转目标 | `https://wenyinos.com/auth/login.php` |
| 中心登出页地址 | 退出跳转目标 | `https://wenyinos.com/auth/logout.php` |

密钥与地址由认证中心管理后台的「应用密钥」页提供。**密钥保存在论坛数据库（插件 kv，后台设置页维护），不随代码入库——本插件代码可全量开源。**

## 依赖

- Xiuno BBS 4.0.x（PHP 8.x）
- curl 扩展
- 网络可达认证中心 API 地址

## 注意事项

- **账号切换 / 中心退出即时生效（v4.13）**：已登录状态下中心票据变更（切换账号）→ 自动切换为新账号；票据被清除/失效（中心已退出）→ 本地登出并跳转中心，随后恢复游客浏览；中心不可达时保持现状（降级静默）
- 修改插件的 `hook/*.php` 后需清空论坛 `tmp/` 编译缓存（后台停用再启用插件会自动清理）
- 本插件所有逻辑均为 hook 注入，未修改任何 BBS 核心文件；停用插件即 100% 恢复原生论坛
